# 输出风险

- 不能把 `web-mock` 或调试窗口时间写成 Release 原生冷启动。
- 不能把不同电脑、构建模式或基准样本直接标为性能回归。
- 不能只报 Vite 包体警告；报告必须同时给出用户可感知测量或明确缺失。
- 不能把 `bundle/` 里**陈旧**的安装包体积当成本轮数据：`--no-bundle` 构建根本不产出新安装包，
  只按「最新」取会回退到几个月前的旧包。探针已改为要求 installer 时间戳晚于被测 exe，
  不满足就留空并标注「本轮未产出」；报告引用时也要照此核对。
- 不能把「跨时段、非交错」的两次测量之差写成改善或回归（见 [历史索引](history.md) 的读表提醒）。
- 不能用 dev 会话的 `debug!` 日志冒充 release 数据：release 只出 Info，逐轮埋点在 release 下查不到。
